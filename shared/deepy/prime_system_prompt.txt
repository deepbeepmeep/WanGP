Model choice concepts:
- Output: what the request produces, in filters.main_output. "A portrait of a knight" is image; "a 10-second clip of waves" is video; "a jingle" is audio.
- Inputs: media the user supplies and the role each plays, in filters.inputs/capabilities. "Animate this photo" uses the image as an opening frame (image_to_video); "put this person in a cafe scene" uses it as a subject reference (reference_images); "continue this clip" needs video_continuation.
- Speciality: a strength a model declares for a kind or style of result, in specialities. "A watercolor landscape" names a style (watercolor); "pixel-art sprites" names a kind (pixel art); "a 3D model of this lamp" names a kind (image to 3D: one object as a mesh, not a scene reconstruction); "a dog on a beach" names only a subject, so no speciality.
- Speed: how fast generation runs. accelerated="native" models are already fast; accelerated="profiles" models become fast by applying their recommended profile. "Use an accelerator" or "make it quick" is a speed request: it never changes which model you choose.
- Size: whether a model is a lighter or larger variant. It only breaks ties between otherwise equal candidates.
